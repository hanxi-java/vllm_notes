## 图像相似性比较的主流做法（除感知哈希外）

> **问题**：库里面的感知哈希方案已经选定，这部分不过多涉及。请根据其他角度（感知相似度指标、深度特征、语义相似、copy detection 等），寻找当前的主流做法，并给出相应的论文依据。
>
> **整理时间**：2026-08-08。引用数为 Google Scholar 大致量级，会随时间增长。

### 一、感知相似度指标（与人眼主观判断对齐）

适用于"判断两张图在人眼看来像不像"，如图像质量评估、生成图与原图的保真度。

**1. LPIPS —— 仍是业界基准**

- Zhang et al., *"The Unreasonable Effectiveness of Deep Features as a Perceptual Metric"*, **CVPR 2018**（引用 10,000+）
- 用 VGG/AlexNet 中间层特征加权求距离，附带 BAPPS 人类判断数据集
- 代码：[github.com/richzhang/perceptualsimilarity](https://github.com/richzhang/perceptualsimilarity)

**2. DreamSim —— LPIPS 之后最受关注的继任者**

- Fu et al., *"DreamSim: Learning New Dimensions of Human Visual Similarity Using Synthetic Data"*, **NeurIPS 2023 (Spotlight)**，arXiv:2306.09344
- 核心思路：把 CLIP + OpenCLIP + DINO 的 embedding 拼接后在 NIGHTS 数据集（~20k 人类相似度三元组判断，扰动由扩散模型合成）上微调，弥合了 LPIPS（低层纹理）与 CLIP/DINO（高层语义）之间的"中层感知"空白，在人类判断一致性上明显优于 LPIPS
- 代码：[github.com/ssundaram21/dreamsim](https://github.com/ssundaram21/dreamsim)

**3. DISTS —— 对纹理生成/重排更鲁棒**

- Ding et al., *"Image Quality Assessment: Unifying Structure and Texture Similarity"*, **IEEE TPAMI 2022**
- LPIPS 对"纹理相同但空间位置打乱"的图像误判严重，DISTS 专门针对这个问题

**4. 鲁棒性改进方向**

- R-LPIPS（*An Adversarially Robust Perceptual Similarity Metric*, 2023）：指出 LPIPS 易受对抗扰动攻击，并给出鲁棒版本。如果用在安全相关场景（如侵权判定的证据），值得参考

### 二、语义级相似 / 图像检索（embedding + 余弦距离）

当前工业界做"以图搜图"、语义去重的绝对主流：提取全局 embedding，算余弦相似度，大规模时用 FAISS/ScaNN 做 ANN 检索。

**1. CLIP —— 语义 embedding 的事实标准**

- Radford et al., *"Learning Transferable Visual Models From Natural Language Supervision"*, **ICML 2021**（引用 30,000+）
- 4 亿图文对对比学习训练，embedding 语义对齐好，还能零样本文本检索

**2. DINOv2 —— 纯视觉自监督，视觉相似性上常优于 CLIP**

- Oquab et al., *"DINOv2: Learning Robust Visual Features without Supervision"*, **TMLR 2024**（引用 5,000+）
- 前作：Caron et al., *"Emerging Properties in Self-Supervised Vision Transformers"*, **ICCV 2021**（DINO，引用 8,000+）
- 实践共识：CLIP 偏"语义/文本对齐"，DINOv2 偏"视觉外观/结构"，做 copy detection 和视觉检索时 DINOv2 往往更强（参见 [CLIP vs DINOv2 对比分析](https://www.aicmty.com/61620.html)）

**3. 实例级检索专用**

- Radenović et al., *"Fine-tuning CNN Image Retrieval with No Human Annotation"*, **TPAMI 2018**（GeM pooling，引用 1,500+）：地标/实例检索经典
- 2024-2025 趋势：直接用 **SigLIP / DINOv2 / DINOv3** 冻结特征 + GeM pooling，不再专门训练

### 三、Copy Detection / 近似重复检测

比语义相似更严格的任务：识别"同一张图经过裁剪、压缩、滤镜、截图、编辑"的副本。这是感知哈希之外的学术主线。

**1. ISC2021 挑战赛（Meta）—— 该领域的基准事件**

- Douze et al., *"The 2021 Image Similarity Dataset and Challenge"*, **NeurIPS 2021 Datasets & Benchmarks**（引用 600+）
- Papakipos et al., *"Results and Findings of the 2021 Image Similarity Challenge"*（[PMLR 论文](https://proceedings.mlr.press/v176/papakipos22a/papakipos22a.pdf)）
- 百万级参考库 + 强对抗编辑（遮挡、PS 合成、截屏翻拍），冠军方案以 CNN 全局描述子 + score normalization 为核心

**2. SSCD —— 自监督 copy detection 描述子（Meta，当前 SOTA 代表）**

- Pizzi et al., *"A Self-Supervised Descriptor for Image Copy Detection"*, **CVPR 2022**（[arXiv:2202.10261](https://arxiv.org/pdf/2202.10261v2.pdf)，引用 300+）
- 用 SimCLR 式对比学习 + InfoNCE 训练 copy detection 专用描述子，ISC2021 上大幅超越监督基线，是后续工作的标准对比对象（作者主页：[edpizzi.com/research/copy-detection](https://edpizzi.com/research/copy-detection/)）

**3. ASL（非对称相似度学习）**

- Yokoo & Inoue, *"A Benchmark and Asymmetrical-Similarity Learning for Practical Image Copy Detection"*, **AAAI 2023**（[arXiv:2205.12358](https://arxiv.org/abs/2205.12358)）
- 针对"被嵌入到大图中的小副本"这种非对称场景，很贴近实际盗图场景

### 四、局部特征匹配（学习式，已取代 SIFT）

需要像素级对应关系、图像对齐、几何验证时。传统 SIFT/ORB 在学术上已基本被学习式方法取代。

- **SuperPoint**：DeTone et al., *"SuperPoint: Self-Supervised Interest Point Detection and Description"*, **CVPRW 2018**（引用 3,000+）
- **SuperGlue**：Sarlin et al., *"SuperGlue: Learning Feature Matching with Graph Neural Networks"*, **CVPR 2020**（引用 3,000+）—— 用 GNN+注意力做特征点匹配，经典组合 SuperPoint+SuperGlue
- **LightGlue**：Lindenberger et al., **ICCV 2023**（[arXiv:2306.13643](https://ar5iv.labs.arxiv.org/html/2306.13643)，引用 1,000+）—— SuperGlue 的轻量加速版，目前工程部署主流
- **LoFTR / 稠密匹配**：Sun et al., *"LoFTR: Detector-Free Local Feature Matching with Transformers"*, **CVPR 2021**（引用 2,500+）—— 免检测器，弱纹理区域更好
- 落地价值：embedding 粗排 + 局部特征几何验证（RANSAC 内点数作为最终分数），是检索系统降误报的标准做法

### 五、汇总对比

| 需求 | 主流方案 | 代表论文 |
|---|---|---|
| 人眼感知像不像 | LPIPS / **DreamSim** | CVPR 2018 / NeurIPS 2023 |
| 语义相似、以图搜图 | CLIP / DINOv2 embedding | ICML 2021 / TMLR 2024 |
| 编辑/盗图副本检测 | SSCD、ISC2021 方案 | CVPR 2022 / NeurIPS 2021 |
| 像素级对应、几何验证 | SuperPoint+LightGlue、LoFTR | CVPRW 2018 / ICCV 2023 / CVPR 2021 |
| 失真质量评估 | SSIM、DISTS | TIP 2004 / TPAMI 2022 |

**实践建议**：如果目标是"图库级相似图检索"，当前最典型的架构是——DINOv2（或 CLIP）提 embedding → FAISS 向量检索召回 Top-K →（可选）LightGlue 几何验证重排。感知哈希可以作为最前端的极廉价粗筛，与深度方案互补。

## 基于像素张量差异的相似性判定算法

> **问题**：我想根据图片之间像素张量的差异来实现相似性，请帮我寻找判定相似的主流算法，并给出各种不同算法之间的对比。
>
> **整理时间**：2026-08-08。按"基于像素张量差异"这一限定，分为三族：**逐点误差族、结构/统计族、感知误差族**（感知族虽然内部有变换，但输入仍是对齐的像素张量）。

### 一、逐点误差族（最快、最朴素）

**1. MSE / PSNR**

- **原理**：均方误差及其对数形式 PSNR = 10·log₁₀(MAX²/MSE)
- **特点**：逐像素差平方，对"图像平移 1 个像素"都会给出很差的分数；与人眼感知相关性差
- **适用**：判等检测、压缩失真测量；不适合近似判定

**2. MAE / 平均绝对差**

- **原理**：逐像素差绝对值平均
- **特点**：比 MSE 对离群点（局部小块改动）更不敏感，适合"局部少量改动"场景

**3. NCC（归一化互相关）**

- **原理**：两图（或滑窗）像素序列的归一化相关系数，范围 [-1, 1]
- **特点**：对整体亮度/对比度的线性变化不敏感（自动去均值归一化）；OpenCV `matchTemplate` 就是它
- **适用**：截图对比、UI 自动化里的模板匹配

**4. 像素差异比例（Diff Ratio）**

- **原理**：|p₁−p₂| > ε 的像素占比
- **特点**：可解释性极强（"99.9% 像素一致"），工业界缓存判等常用；ε 可调容忍噪点

### 二、结构/统计族（对扰动更鲁棒）

**5. SSIM ⭐（结构相似度）**

- **论文**：Wang et al., *"Image Quality Assessment: From Error Visibility to Structural Similarity"*, **IEEE TIP 2004**（引用 45,000+）
- **原理**：在局部滑窗上分别比较**亮度、对比度、结构**三个分量，乘积得 [-1, 1] 分数
- **特点**：与人眼感知相关性远好于 PSNR；对轻微压缩、噪声鲁棒；像素级方案中**性价比最高的通用选择**

**6. MS-SSIM**

- **论文**：Wang et al., Asilomar 2003（引用 7,000+）
- **原理**：SSIM 的多尺度版本，在多个下采样分辨率上计算后加权
- **特点**：比 SSIM 对缩放、轻微失配更鲁棒，代价是计算量约 5 倍

**7. 直方图比较**

- **原理**：对颜色/灰度直方图算距离：Correlation、Chi-Square、Intersection、Bhattacharyya（OpenCV `compareHist` 内置四种）
- **特点**：**对平移、旋转、裁剪完全不变**——这是优点也是致命缺点：两张构图完全不同的图只要配色接近就得高分。只适合粗筛，不能单独做判定

### 三、感知误差族（像素输入，但建模人眼，精度最高）

**8. Butteraugli（Google）**

- **原理**：在 XYB 色彩空间做多尺度心理视觉建模，输出差异分数（0 = 完全相同）
- **特点**：有著名的"视觉无损阈值 ≈ 1.0"；在 CID22 主观数据集上 SRCC ≈ 0.79；JPEG XL 生态标准工具

**9. SSIMULACRA2（Cloudinary）⭐**

- **原理**：与 Butteraugli 同源的心理视觉基础（多尺度 SSIM + 边缘伪影 + 高频细节），但针对主观数据集做了标定
- **特点**：**目前公认最准的像素级感知指标**，CID22 上 SRCC ≈ 0.89，高分区间准确率可达 98%；100 = 数学无损，90+ = 视觉无损；有 [GPU 实现](https://github.com/Line-fr/Vapoursynth-HIP-SSIMU2)（1080p 图像比 CPU 快 10 倍以上）
- 参考：[官方分数解读](https://github.com/cloudinary/ssimulacra2)、[Halide fmetrics 基准](https://halide.cx/blog/fmetrics/)

**10. FLIP（NVIDIA）**

- **论文**：Andersson et al., *"FLIP: A Difference Evaluator for Alternating Images"*, **SIGGRAPH 2020**
- **原理**：感知误差图（0-1，越低越好），输出逐像素的"人眼可察觉差异"热力图
- **特点**：为图形渲染对比设计，可生成空间误差图定位差异区域；需要逐对计算，成本偏高

### 四、横向对比表

| 算法 | 速度 | 与人眼一致性 | 抗压缩/重编码 | 抗缩放 | 输出可解释性 | 适合缓存场景？ |

| MSE/PSNR | ⚡极快 | ❌ 差 | ❌ 差 | ❌ 差 | 中 | 仅判等 |

### 五、针对"像素张量相似→复用"场景的建议

1. **前提条件**：像素比较要求两图严格对齐（同尺寸、同色彩空间）。在多模态 pipeline 里，比较应该发生在**预处理之后的张量**上（ViT 前都做了 resize/crop/归一化到固定尺寸），这样天然对齐，原始图像尺寸差异被消除——这是这个方案能成立的关键。

2. **推荐组合（成本递增的三档）**：
   - **L1 判等**：Diff Ratio（ε 很小）或预处理张量的哈希 → 完全相同，直接复用
   - **L2 近似**：**SSIM > 阈值（如 0.98）** → 主力判定。SSIM 有成熟 GPU 实现（`torchmetrics`、`kornia`），batch 比较 1080p 图像在毫秒级
   - **L3 高置信校验**（可选）：SSIMULACRA2 > 90 → 用于离线标定阈值和抽检 L2 的误判，不建议上在线路径

3. **必须实测标定的风险点**：像素级方法对"同一场景拍了两张几乎一样的照片"（连拍、视频相邻帧）会给高分，但这两张图在语义上**确实可能等价**——这对缓存复用反而是好事。真正的风险是**小但关键的差异**：截图里改了一个数字、图片角落的水印变化，SSIM 全局平均后可能仍有 0.99。建议加一层**分块 SSIM 取最小值**（min over patches）而不是全局平均，局部差异无处遁形，这是工业界做截图 diff 的标准技巧。

4. **离线评测方法**：用数据增强（JPEG 重压缩 q=75/90、缩放 0.8x/1.2x、轻微裁剪）生成"应复用"正样本，用相似但不同的图做负样本，扫阈值画 PR 曲线选工作点。

## SSIMULACRA2 算法详解

> **问题**：请详细解释一下 SSIMULACRA2 算法的原理，并解释其主流实现。再给出一些相关的主流论文。
>
> **整理时间**：2026-08-08。

### 一、SSIMULACRA2 是什么

**SSIMULACRA2**（Structural SIMilarity Unveiling Local And Compression Related Artifacts, v2）是 Cloudinary 的 Jon Sneyers（JPEG XL 核心作者之一）于 2022 年发布的开源感知图像质量指标，是 2017 年 SSIMULACRA v1 的重写版。它的设计目标非常明确：**专检测有损压缩（JPEG/WebP/AVIF/JPEG XL 等）产生的伪影**，输出 0–100 的分数（越高越好，100 = 数学无损，90+ ≈ 视觉无损），在 CID22 主观数据集上与人类打分的秩相关 SRCC ≈ 0.89——是目前像素级全参考指标中与人类感知一致性最高的。

它的技术谱系：**SSIM（2004）的多尺度结构思想 + Butteraugli（Google, 2015-16）的 XYB 心理视觉色彩空间**，再针对压缩伪影做了定向强化。

### 二、算法原理（五个步骤）

**第 1 步：色彩空间转换（sRGB → 线性 RGB → XYB）**

两张输入图（参考图 + 失真图）先去掉 gamma 转到**线性 RGB**，再变换到 **XYB 色彩空间**：

- XYB 源自 Butteraugli，模拟人眼视网膜视锥细胞（LMS）响应：Y ≈ 亮度，X ≈ L−M 红绿对抗通道，B ≈ S 蓝色通道（用 B−Y 表示），传递函数为立方根
- 相比 v1 用的 CIE Lab，XYB 更贴合人眼对蓝色空间分辨率低的特性（S 视锥在中央凹密度极低），压缩伪影在 B 通道的可见性被正确降权

**第 2 步：多尺度分解（6 个尺度）**

在**线性 RGB 下**逐级 2 倍下采样（感知上正确的做法，v1 是在 gamma 空间做的，是个缺陷），得到 1:1、1:2、…、1:32 共 **6 个尺度**。多尺度的意义：人眼看大图时实际是在不同"观看距离"上感知的，块状伪影在粗尺度上明显，纹理损失在细尺度上明显。

**第 3 步：每个尺度 × 每个通道计算 3 张误差图**

对每个尺度、每个 XYB 通道，计算三张互补的误差图：

1. **SSIM 误差图** —— 修正版 SSIM（去掉了原版会导致 gamma 被施加两次的亮度分母项），衡量结构相似性的局部损失
2. **边缘伪影图（ringing/blockiness）** —— 惩罚"失真图里出现了原图平滑处的边缘"，对应振铃效应、蚊式噪声、块效应、色带
3. **细节丢失图（smoothing/blur）** —— 惩罚"原图有细节处失真图变平滑了"，对应模糊、纹理抹除

这一步是 SSIMULACRA2 的灵魂：压缩伪影本质上就两类——**凭空多出边缘**（量化粗糙）和**丢失原有细节**（过度平滑），两张图分开建模。

**第 4 步：范数聚合（108 个子分数）**

6 尺度 × 3 通道 × 3 误差图 = **54 张误差图**。每张图计算两种范数：

- **1-范数（均值）**：整体平均误差
- **4-范数**：突出局部最差区域的误差（人眼对"一处明显瑕疵"比"整体轻微劣化"更敏感，这一点借鉴了 Butteraugli 用高阶范数聚合的思路）

共 **108 个子分数**。

**第 5 步：加权融合 + 非线性映射**

108 个子分数做**加权求和**（权重用 Nelder-Mead 单纯形搜索在 CID22、TID2013、KADID-10k、KonFiG-IQA 四个主观数据集上拟合得到），再经过一个多项式非线性重映射，输出最终 0–100 分数。

**关键特性**

- **非对称**：SSIMULACRA2(a, b) ≠ SSIMULACRA2(b, a)。因为"多出边缘"和"丢失细节"惩罚力度不同，**参数顺序必须固定为（参考图， 失真图）**——在缓存判定场景里，就是（缓存图， 新图）
- **分数解读**（[官方指南](https://github.com/cloudinary/ssimulacra2)）：100 = 数学无损；90+ = 视觉无损（flicker 测试不可察觉）；80+ = 很高质量；70+ = 高质量；50 以下伪影明显
- **局限**：为压缩伪影调优，不是通用失真指标；两张图必须严格对齐（尺寸相同、无平移），不适合比较构图不同的图

### 五、回到缓存判定场景

SSIMULACRA2 有两个特性对缓存复用判定特别有价值：

- **"90 分 ≈ 视觉无损"是一个现成的、经过主观数据标定的阈值**，不用从零标定——可以先用 `SSIMULACRA2(缓存图, 新图) ≥ 90` 作为初始工作点，再用业务数据微调
- **非对称性正好是需要的语义**：关心的是"新图相对缓存图丢失了什么/多出了什么"，而不是对称相似度

但要记住它的盲区：**两图必须严格对齐**。在预处理后的固定尺寸张量上做比较，正好满足这个前提；如果未来想比较不同分辨率的同一张图，SSIMULACRA2 会直接失效，那种情况要回退到 embedding 方案。
